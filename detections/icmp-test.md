# Detection Report - ICMP Test

## Summary

A controlled ICMP test was performed inside the Home SOC Lab to validate the complete detection pipeline from network activity to SIEM alert generation.

The test confirmed that traffic generated by the test endpoint was successfully detected by Suricata, forwarded through remote logging and processed by Wazuh.

## Detection Source

Suricata custom rule:

```text
SID: 1000001
Signature: SOC LAB ICMP TEST
```

Wazuh rule:

```text
Rule ID: 100101
Level: 5
Description: OPNsense Suricata ICMP test alert
```

## Test Activity

ICMP Echo Request traffic was generated from the monitored test system.

Example:

```powershell
ping <TEST_DESTINATION>
```

## Detection Flow

```text
ICMP Traffic
     |
     v
 OPNsense
     |
     v
 Suricata
     |
     v
 EVE JSON
     |
     v
 Remote Syslog
     |
     v
 rsyslog
     |
     v
 Wazuh Decoder
     |
     v
 Wazuh Rule 100101
     |
     v
 Alert
```

## Observed Event

The Suricata event contained information such as:

- protocol: ICMP
- event type: alert
- signature ID: 1000001
- signature: SOC LAB ICMP TEST
- Suricata severity: 3

Wazuh processed the event and generated a level 5 alert.

## Analysis

The alert was expected and generated as part of a controlled validation test.

The event confirms that:

- Suricata was monitoring the correct network segment
- the custom Suricata rule was active
- EVE JSON events were generated
- remote syslog forwarding was working
- Wazuh successfully decoded the event
- the custom Wazuh rule matched the Suricata signature

## Classification

```text
Type: Detection validation
Activity: ICMP Echo Request
Risk: Low
Expected activity: Yes
Response required: No
```

## Conclusion

The test successfully validated the end-to-end detection pipeline.

No malicious activity was identified.

The rule remains useful as a simple health check for validating communication between Suricata and Wazuh.
