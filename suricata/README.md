# Suricata

## Purpose

Suricata is used to monitor network traffic and detect suspicious activity.

## Configuration

Suricata was enabled on the OPNsense firewall.

## Troubleshooting

During the initial configuration, Suricata was running but no alerts were being generated.

The following components were verified:

- monitored interface
- IDS rules
- Suricata service status
- alert logs
- network traffic
