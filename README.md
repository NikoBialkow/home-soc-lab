# Home SOC Lab

## Overview

This project documents the development of my personal Security Operations Center (SOC) lab.

The environment is designed to practice:

- security monitoring
- network traffic analysis
- intrusion detection
- log analysis
- incident investigation
- firewall configuration
- SIEM administration

## Technologies

The lab currently uses:

- VirtualBox
- Ubuntu Server
- Windows 10
- Wazuh
- OPNsense
- Suricata
- Wireshark

## Project Goals

The main goal of this project is to gain practical experience with tools and workflows commonly used by SOC analysts.

The environment will be used to simulate attacks, generate security events and investigate alerts.
