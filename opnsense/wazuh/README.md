# Wazuh

## Purpose

Wazuh is used as the central SIEM/XDR platform in the Home SOC Lab.

Its main role is to collect, analyze and correlate security events from monitored systems.

## Role in the Lab

Wazuh is used for:

- security event monitoring
- log collection
- endpoint monitoring
- alert generation
- event analysis
- basic incident investigation
- centralized security visibility

## Environment

Wazuh is deployed on Ubuntu Server inside the VirtualBox lab environment.

The Wazuh server acts as the central monitoring system for the lab.

## Components

The Wazuh environment includes:

- Wazuh Manager
- Wazuh Dashboard
- Wazuh Indexer
- monitored endpoints

## Current Configuration

The current setup includes:

- Wazuh installed on Ubuntu Server
- access to the Wazuh Dashboard
- basic event monitoring
- preparation for endpoint monitoring
- preparation for Suricata log integration

## Monitoring Goals

The Wazuh platform will be used to monitor security events generated by:

- Ubuntu Server
- Windows 10
- Suricata
- authentication logs
- network-related events

## Suricata Integration

One of the planned goals is to integrate Suricata alerts with Wazuh.

This will allow network intrusion alerts to be analyzed together with endpoint and system events.

Suricata documentation:

[Suricata documentation](../suricata/README.md)

## Troubleshooting

During the setup process, configuration and access issues required verification of:

- Wazuh service status
- dashboard access
- configuration files
- log availability
- integration paths
- alert generation

Troubleshooting was used to verify whether the issue was related to the Wazuh platform itself or to external log sources.
