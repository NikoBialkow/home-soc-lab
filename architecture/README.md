# Lab Architecture

## Overview

The Home SOC Lab is built in VirtualBox and contains multiple systems used for network monitoring, endpoint monitoring, intrusion detection and security event analysis.

The environment is designed so that test traffic can be generated inside the lab and observed by OPNsense, Suricata and Wazuh.

## Current Architecture

```text
                         Internet
                            |
                            |
                    VirtualBox NAT
                            |
                         OPNsense
                      Firewall / Gateway
                            |
                            |
                        SOC-LAN
                            |
              +-------------+-------------+
              |                           |
              |                           |
      Windows Test VM                Other Lab VMs
              |
              |
       monitored traffic
              |
              v
          Suricata
       running on OPNsense
              |
              |
        EVE JSON / Syslog
              |
              v
      Ubuntu / Wazuh Server
              |
              v
        Wazuh Dashboard
```

The main Windows workstation runs VirtualBox and is connected to the home network.

Exact host addresses and environment-specific addressing are intentionally excluded from the public repository.

## Main Components

### OPNsense

OPNsense provides:

- firewalling
- routing
- DHCP
- network segmentation
- Suricata IDS
- remote syslog forwarding

The environment contains:

```text
External network interface
Internal SOC-LAN interface
```

The internal interface creates the isolated SOC-LAN network used by test systems.

## Windows Test VM

The Windows test endpoint is connected to SOC-LAN.

It is used to:

- generate controlled network traffic
- test detection rules
- run Nmap scans
- generate Sysmon telemetry
- verify Wazuh alerts

## Ubuntu / Wazuh Server

The Ubuntu Server provides the central monitoring and log analysis platform.

Main services include:

- Wazuh Manager
- Wazuh Dashboard
- rsyslog
- Suricata log ingestion
- custom Wazuh decoders
- custom detection rules

## Network Segments

The environment is divided into:

### Home Network

Used for:

- management
- the main workstation
- the Wazuh server
- administrative access

### SOC-LAN

Used for:

- monitored endpoints
- controlled network testing
- IDS validation
- future Red Team / Purple Team exercises

Exact subnet ranges are intentionally not published.

## Traffic Monitoring

Suricata monitors traffic on the internal lab segment.

This allows traffic generated by SOC-LAN systems to be inspected before relevant alerts are forwarded to Wazuh.

## Current Detection Sources

The lab currently collects security telemetry from:

- Windows Sysmon
- Wazuh Agent
- OPNsense
- Suricata
- rsyslog
- network packet captures

## Security Considerations

The public repository intentionally excludes:

- exact host IP addresses
- full subnet addressing
- MAC addresses
- authentication information
- firewall backup files
- private keys
- certificates
- complete production-style configuration files

## Future Architecture

Future expansion may include:

- Kali Linux
- Windows Server
- Active Directory
- vulnerable Linux hosts
- additional isolated network segments
- Red Team and Purple Team testing
